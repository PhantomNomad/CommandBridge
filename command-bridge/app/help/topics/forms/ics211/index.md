# ICS 211 - Check-In List

The ICS 211 records people and equipment as they arrive at the incident. It shows when each one arrived, where they were first sent, and what is needed to send them home again (home base, how they travelled, and so on). It is the starting point for resource tracking, demobilization and cost records.

- **Usually prepared by:** whoever runs check-in at the Incident Command Post, a staging area, base, camp or air base, or the Communications Centre, or a Resources Unit recorder at the ICP.
- **Who gets it:** the Resources Unit (which keeps the master list of everyone and everything checked in), the Demobilization Unit and the Finance/Administration Section.

General steps for saving, signing and printing are in [Working with ICS forms](help:forms/working_with_forms).

## The page header

| Field | What to enter |
|---|---|
| Incident Name, Incident Number | Filled in from the incident. |
| Start Date/Time | When this check-in list was started. |
| Check-In Location | Where check-in is happening: Base, Camp, Staging Area, ICP, Helibase or another place. Be specific. |

## Each check-in entry

| Field | What to enter |
|---|---|
| Agency / CAT. | The agency, and the resource category if it helps (boats, aircraft and so on). |
| Kind, Type | The resource kind and type, using your agency's or the province's resource typing. Leave blank for individual people. |
| ST/TF | Whether it is part of a Strike Team or Task Force, if that applies. |
| Resource Name or ID # | The resource's name or unique identifier. For a Strike Team or Task Force, list the IDs of each unit. For individual people, enter the person's name. |
| Order / Request #, LDW | The order or request number the dispatching agency gave it, and the last day worked if your agency tracks it. |
| Date/Time Check-In | When it arrived (24-hour clock). |
| Leader's Name | The operator's name for equipment, or the Strike Team or Task Force leader. |
| Total # Personnel | Everyone with the resource, including the leader. |
| Contact Information | A phone number and/or email for the resource. |
| Home Unit / Agency | Where the resource normally works. This may not be where it left from. |
| Departure Point | Where it left from to come here, and when. |
| Method of Travel | How it got here: bus, own truck, engine, personal vehicle and so on. |
| Incident Assignment | What it was dispatched to do. |
| Other Qualifications | Any other qualifications useful on this incident. |
| Remarks or Comments | Anything else. |
| Sent to Resource Unit | When this entry went to the Resources Unit, and who sent it (initials). |

Saved entries are listed under **Existing Check-In Entries**.

## Where entries also come from

- Resources ordered on an [ICS 213RR](help:forms/ics213rr_v2/index) and received by the [Resources Unit](help:forms/resources/index) can be added here with **Add to ICS 211**.
- Check-in entries feed the resource summary on the [ICS 209](help:forms/ics209/index).
