# ICS 230 - Daily Meeting Schedule

The ICS 230 lists the meetings and briefings planned for the operational period, with their times and places, so everyone on the incident management team knows when and where to be. It is optional and is often posted as a wall chart.

- **Usually prepared by:** the Situation Unit, at the start of each operational period.
- **Who gets it:** the Command Staff and each Section, and it is posted on information boards. The signed original goes to the Documentation Unit.

General steps for signing and printing are in [Working with ICS forms](help:forms/working_with_forms).

## Adding a meeting

| Field | What to enter |
|---|---|
| Meeting Type | The kind of meeting, for example a briefing or the planning meeting. |
| Scheduled Date/Time | When it starts (24-hour clock). |
| Meeting Title, Purpose | A short name and what it is for. |
| Location | Where it is held, or the call-in details. |
| Chair Name, Chair Position/Title | Who runs it. The chair gets the reminder described below. |
| Attendees Summary | Who should attend. |
| Status | See below. |
| Display Order | Use this to change the order of meetings that start at the same time. |
| Notes | Anything else. |

The meeting list shows each meeting's time, title and purpose, location and chair. **Delete** removes a meeting added by mistake; for a meeting that won't happen, set it to Cancelled instead so the record stays.

## Meeting status

Each meeting has a status:

| Status | Meaning |
|---|---|
| Scheduled | Planned for the time shown |
| Tentative | Planned, but the time or need isn't confirmed |
| Completed | The meeting was held |
| Cancelled | It won't happen; it no longer shows under upcoming meetings on the dashboard |

**Only Completed meetings count as held.** Each one shows as "Meeting held: ..." on everyone's [ICS 214](help:forms/ics214/index) for that operational period. While the ICS 230 is a draft, anyone who can edit it can change a meeting's status with **Edit**. Once it is signed, the schedule is locked: adding, moving or removing a meeting needs **Revise** (see [Working with ICS forms](help:forms/working_with_forms)).

Once a meeting's start time has passed and it is still Scheduled or Tentative, a **Was it held?** button shows next to its status. It opens a page with **Completed (meeting was held)** and **Cancelled** buttons and an optional note. This works even after the ICS 230 has been signed, because it records what happened rather than changing the plan. The chair, the Incident Commander, the Planning Section Chief and anyone who can edit the ICS 230 can use it.

## Reminders

If a meeting is still Scheduled or Tentative an hour after its start time, the **chair**, the **Incident Commander** (or Unified Command) and the **Planning Section Chief** each get a dashboard notification asking whether it was held. Opening it shows the same **Was it held?** page, which also works for meetings in an earlier operational period. The reminder disappears as soon as the status is changed.

## ECC display

The Meetings tab on the ECC display lists the period's meetings. It scrolls to the **last meeting held** (the most recent Completed one), so the upcoming meetings are on screen. Older meetings are dimmed above it.
