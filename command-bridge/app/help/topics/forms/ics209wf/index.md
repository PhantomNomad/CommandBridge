# ICS 209-WF - Wildfire Incident Status Summary

The ICS 209-WF is the wildfire version of the [ICS 209](help:forms/ics209/index). It works the same way: one report per operational period, the same auto-fill and **Insert from ...** buttons, the same resource summary and the same sign-off. Read the ICS 209 help for how the report works and what goes in each block.

What is different for wildfire:

- **Status (Block 9)** uses the wildfire stages: OC (out of control), BH (being held), UC (under control) or O (out). It is required before you can submit, in place of the incident definition.
- **Block 28** asks for observed fire behaviour as well as significant events.
- **Block 29** asks for the primary FBP (Fire Behaviour Prediction system) fuel type.
- The damage table (Block 30) splits residences into single, multiple and mixed commercial/residential.

The 209 and 209-WF are kept as separate reports. Use the one your agency asks for; you don't need both.
