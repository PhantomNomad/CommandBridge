# ICS 207 - Incident Organization Chart

The ICS 207 is a wall chart of the incident organization: the positions that are active and who is in each one. It is meant to be posted at the Incident Command Post and other incident locations. It is **not** part of the Incident Action Plan.

- **Usually prepared by:** the Resources Unit Leader. The Incident Commander checks it. Make a new one each operational period, and update it when the organization changes.
- **Who gets it:** posted on the wall. The signed original goes to the Documentation Unit.

General steps for signing and printing are in [Working with ICS forms](help:forms/working_with_forms).

## How it is filled in

Like the [ICS 203](help:forms/ics203/index), the chart is built from the people **currently assigned** to incident positions. You don't type on it. Change the assignments in [Position assignments](help:operational_periods/assignments) and the chart updates.

The page lists each position's code, name and the person assigned. **Preview PDF** places each person in the matching box of the official chart.

## Guidance from the form

- Show only the positions that are active. Add boxes for Agency Representatives and Operations elements as needed.
- Use at least a first initial and last name for everyone. Show the agency for Unified Commanders.
- If more than one person holds a position (for example after a shift change), all their names print in the box, separated by semicolons.
- The chart is designed to be printed large. The PDF prints at letter size; enlarge it on a plotter or larger printer for the wall if you can.
