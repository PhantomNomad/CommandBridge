# ICS 205 - Incident Radio Communications Plan

The ICS 205 lists every radio channel or talkgroup in use for the operational period and who it is assigned to, down to Division/Group level. Channel details from it are copied onto each [ICS 204](help:forms/ics204/index). It is part of the Incident Action Plan (IAP).

- **Usually prepared by:** the Communications Unit Leader, who passes it to the Planning Section Chief for the IAP.
- **Who gets it:** everyone who receives the IAP. The signed original goes to the Documentation Unit.

General steps for saving, signing and printing are in [Working with ICS forms](help:forms/working_with_forms).

## What goes in each block

| Block | What to enter |
|---|---|
| Incident Name, Operational Period | Filled in for you. |
| 4. Basic Radio Channel Utilization | One row per channel or talkgroup. Press **Add Channel Row** for more. |
| System/Type | Whose radio system it is, when more than one is used (for example the agency that owns it), and its type (VHF, UHF, cellular, satellite). |
| Channel | A channel number, either the one programmed into the incident radios or just a line number for reference. Up to the Communications Unit Leader. |
| Function | What the channel is for: Command, Tactical, Ground-to-Air, Air-to-Air, Support, Dispatch and so on. |
| Frequency/Tone | Transmit and receive frequencies, and any tone (CTCSS) or network access code. People programming radios in the field need this. |
| Assignment | The Branch, Division, Group or Section that uses the channel. |
| Remarks | Anything else about that channel. |
| Special Instructions | Notes that apply to the whole plan, such as cross-band repeaters or channel-change times. |
| Prepared By | Normally the Communications Unit Leader. |

## Tips

- Phone, email and pager contacts go on the [ICS 205A](help:forms/ics205a/index), not here.
- Fill in a 205 for each operational period, even if nothing changed, so the IAP for that period is complete. The [ICS 202](help:forms/ics202/index) can't be approved until a 205 is saved for the period.
