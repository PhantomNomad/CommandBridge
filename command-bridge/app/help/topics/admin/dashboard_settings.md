# Dashboard Panels

Choose which panels each position sees on its [dashboard](help:dashboard/index). Each row is a position, and each column is a panel. Tick the panels that position should see, then press **Save**.

- The **Everyone** row applies to every signed-in user, whatever their position.
- People see the Everyone panels **plus** the panels of every position they hold. Someone covering two positions gets both sets.
- SysAdmins always see every panel.
- Anyone can press **Show everything** on their dashboard. These choices only decide what is shown first. What people can open is still set in [Form Permissions](help:admin/form_permissions).
- **Reset to defaults** puts back the starting choices: the basics for everyone, the IAP and staffing panels for command and planning, and the queues for the Resources Unit, Logistics and Finance/Admin.
- Changes apply at once and are written to the [audit log](help:audit/index).

Positions come from the [Roles Catalogue](help:admin/role_catalogue). A new position starts with only the Everyone panels until you tick some for it.
